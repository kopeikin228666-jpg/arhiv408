# АРХИВ 408 — рабочий архив команды

Канал @arhiv408: тёмные пиксельные хоррор-ролики и посты про реальные загадки. Ведущий — «408».

- `project/` — код и материалы: сборщик эпизода `project/team/host/make_ep1e.py`, персонаж `project/edit/host.py`,
  лаборатория `project/edit/room.py`, рендер ролика `project/edit/render.py`, сведение `project/edit/mix2.py`,
  мастеринг `project/team/host/ep_level.py`, палитра `project/look/pixelize.py`, голоса `project/audio/`.
- `project/team/insta/` — отчёт аналитика и контент-план; `project/team/scripts/` — сценарии.
- `project/team/posts/` — карусели; `project/team/brand/` — аватар, баннер, обложки актуальных.
- `project/*.md` — брифы агентов, библия персонажа, порядок совета директоров.
- `office408.html` — исходник страницы «Офис 408».
- `deliverables/` — готовые файлы (лёгкие версии).

Тяжёлые промежуточные файлы (рендеры кадров, исходные клипы, черновые миксы) сюда не входят: они пересобираются скриптами.
