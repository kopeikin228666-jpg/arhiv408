# «408» — персонаж-рассказчик канала (паспорт)

Постоянный ведущий всех видео канала «АРХИВ 408». Он говорит со зрителем от первого лица, «открывает дела»,
реагирует на жуткие моменты, задаёт вопрос в конце. Живёт в своей лаборатории-архиве.

## Внешность (утверждено клиентом 25.10.2026)
- Маленький, но не чиби-шарик: пропорции ближе к человеку, силуэт как у смерти — широкий.
- Высокий острый глубокий капюшон. ЛИЦА НЕТ — внутри абсолютная тьма.
- Глаза: высоко в капюшоне, две узкие тяжёлые щели, внутренний край опущен (взгляд исподлобья),
  тлеют тёмно-красным, горит только центр. Без бликов, не «мило».
  - говорит → щели разгораются; злится/жуткий момент → щели сужаются и вспыхивают; моргает → глаза гаснут, только тьма.
- Рот: цифровая звуковая волна, ТОЛЬКО когда говорит; тусклая, рваная, «сломанный сигнал». Молчит — во тьме ничего.
- Плащ: длинный, чёрный, рваный, из краёв валит тёмный дым; без разреза спереди.
- Из-под плаща — большие тяжёлые чёрные ботинки. Всё чёрное.
- Вокруг него темнота «съедает» свет (аура), с капюшона поднимается чёрный дым.
- Палитра: 18 цветов из look/pixelize.py, пиксель-арт на сетке 180×320 (×6 = 1080×1920).
- НЕ похож на чужих персонажей (дементоров и т.п.) — это свой оригинальный образ.

## Голос
- Голос рассказчика Callum (ElevenLabs voice_id N2lVS1w4EtoT3dr4eOWO) + обработка «из тьмы» (без питча).
- Фирменная фраза: «Я — четыреста восемь… Открываю дело.» (сгенерирована, файл:
  https://cdn.creativeclaw.co/u/19ee9e77/audio/52f9e44c-e355-4e2e-a99c-96f68f495676.mp3 — нужно положить в Музыку).
- Номер дела показывается на экране («ДЕЛО №001»), фраза одна на все видео.

## Заставка в начале каждого видео
Глитч-телепорт: помехи на весь экран → он появляется в своей комнате → загораются глаза → фраза
«Я — 408. Открываю дело…» (рот-волна по голосу) → на главном мониторе «ДЕЛО №…» → переход в историю.

## Его лаборатория-архив (room.py)
Тёмная комната: стена старых ЭЛТ-мониторов (на главном — открывающийся красный глаз / номер дела / кадр истории,
волна его голоса, REC, радар, глифы), по бокам мейнфреймы с катушками и лампочками, стол с папками «ДЕЛО»,
рукописью, кружкой, кресло, кабели с потолка, пятно света от мониторов на полу, пыль, полумрак.
Можно расширять: колбы, пробирки, доска с нитками-связями, сейф с делами, артефакты прошлых выпусков.

## Файлы
- edit/host.py — персонаж: sprite_img(t, amp, blink, look, wave_seed, mood) и draw(g, cx, by, t, amp, ...)
  (amp = громкость голоса 0..1 → рот и яркость глаз; mood 'calm' | 'scary'; aura = тьма и дым).
- team/host/gen1_sprite.png — исходный силуэт (сгенерирован и переведён в палитру).
- edit/room.py — комната: frame(t, amp, mood, blink, look) → кадр 180×320.
- Старые версии: host_chibi.py, host_v2…v6.py (не использовать).
